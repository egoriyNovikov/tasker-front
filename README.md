# Tasker

Приложение для задач. Стек: Vue 3, Pinia, Vue Router.

Макет первой страницы — тёмная тема, узкий сайдбар, список задач и поле ввода снизу.

## Запуск

```sh
npm install
npm run dev
```

Через Docker:

```sh
docker compose up -d
```

Открыть [http://localhost:5173](http://localhost:5173).
